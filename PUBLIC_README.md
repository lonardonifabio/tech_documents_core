## 🚀 Project Status: Migrated to Private Repository

This project has been **migrated to a private repository** for enhanced security and better management of the document collection.

## 📋 About

The AI & Data Science Document Library is an automated collection of over **1,200+ curated documents** covering:

- 🤖 **Artificial Intelligence**
- 🧠 **Machine Learning** 
- 📊 **Data Science**
- 📈 **Analytics**
- 🔬 **Research Papers**
- 💼 **Business Applications**

## ✨ Features

- **Advanced Boolean Search** - Search with AND, OR, NOT operators
- **Interactive Knowledge Graph** - Visualize document relationships
- **Smart Filtering** - Filter by category, difficulty, and keywords
- **PDF Preview** - In-browser document preview
- **Responsive Design** - Works on all devices
- **Auto-categorization** - AI-powered document classification

## 🛠️ Technology Stack

- **Frontend**: Astro + React + TypeScript
- **Styling**: Tailwind CSS
- **Search**: Advanced boolean search algorithms
- **Visualization**: D3.js for knowledge graphs
- **Deployment**: GitHub Pages / Vercel
